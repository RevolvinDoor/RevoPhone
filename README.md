# RevoPhone 📱

给酒馆里的角色一部手机，也给你一个管理剧情的入口。

RevoPhone 是面向 **SillyTavern / TauriTavern** 的扩展。你可以和角色私聊、接电话、刷朋友圈，为正文配音与配图，也可以管理角色的当前状态、衣柜装备和购物商城。

**当前版本：1.4.4** · SillyTavern 最低版本：**1.13.2** · 支持桌面与 Android 界面

[使用说明](使用说明.md) · [更新日志](更新日志.md) · [Fish 订阅积分接入](Fish订阅积分接入.md) · [反馈问题](https://github.com/RevolvinDoor/RevoPhone/issues)

## 安装与更新

1. 打开酒馆的「扩展 → 安装扩展」。
2. 粘贴下面的仓库地址，完成安装后刷新页面。
3. 点击悬浮球，或从输入框左侧魔法棒菜单的「小手机」打开；扩展设置中也有「RevoPhone → 打开小手机」。

```text
https://github.com/RevolvinDoor/RevoPhone
```

在 TauriTavern 中同样通过扩展管理安装。插件的基础功能无需另外部署服务；文字、语音和绘图按需要连接对应接口。

更新时，在扩展管理中点击更新，再刷新页面。Android 上可重新打开扩展或重启 TauriTavern。升级前可在「设置 → 备份到文件」保存一份资料。

## 第一次使用

先选一项你想用的功能，不需要一次配齐所有接口。

| 想做什么 | 从哪里开始 |
| --- | --- |
| 和角色发消息 | 「Soul → ＋」选择角色。文字功能默认使用酒馆当前连接的模型。 |
| 听角色说话 | 在「引擎」配置语音服务，再到「角色」为角色绑定音色；正文台词旁的声波用于播放。 |
| 给剧情配图 | 在「引擎」配置绘图连接，在「绘图」选择引擎；「设置 → 正文出图」控制正文绘图规则。 |
| 管理角色外观和穿戴 | 先在「角色」确认主角、普通角色与旁白分类，再打开「角色状态」和「衣柜」。 |
| 上架或购买商品 | 打开「购物商城」购买；点击「＋ 进货上架」可手动录入、AI 设计或批量导入。 |

正文出图的自动生成选项在「绘图 → 正文出图」中设置。主角和旁白不参与电话呼叫；需要通话的联系人请设为普通角色。

## 手机里的互动

- **聊天与电话**：私聊、群聊、语音消息、红包、转账、拍一拍和来电。角色用绑定的音色说话，你可以打字回复；手机聊天也可通过「带进剧情」接入正文。
- **朋友圈与论坛**：在 Soul 的「动态」中查看朋友圈，发帖、点赞、评论；论坛提供话题、帖子与楼层互动。
- **查手机**：查看角色的聊天、相册、备忘录、搜索记录等。查手机快照按角色卡与正文聊天隔离，保留的旧聊天可恢复对应记录。
- **记忆与正文联动**：聊天可整理摘要并检索相关记忆；正文中的消息、照片、转账、电话和动态可同步到手机。

## Soul：发现这个世界里的新朋友

原「聊天」App 更名为 **Soul**，消息、发现、联系人与动态集中在同一入口。

- **发现**：填写要求或留空随机，每次刷新产生三份简单交友资料，并分别生成一张竖版全身照片。明确要求应用于每个人，并参与当前世界书扫描；人物保存本次要求，喜欢后继续沿用。
- **陌生人来信**：点击按钮，一位热情、配合意愿高的新角色带着资料、照片和招呼来认识你。
- **喜欢后再了解**：喜欢或接受来信后，才扩写完整人物资料，登记到「角色」与「角色状态」，进入私聊。已有图片和人物档案复用。
- **公开主页**：独立填写网名、头像、公开身份、兴趣等。首次保存自动记为默认，新聊天带入副本；之后可只改本聊天、另存模板或更新默认模板。
- **陌生人知识范围**：Soul 人物的私聊、通话与好友申请只接收公开主页及双方交流资料，不提供真实玩家人设、正文经历或其他联系人的记忆。
- **按正文聊天存档**：发现、来信、人物和私聊随当前正文聊天保存。新聊天重新认识，旧聊天恢复进度；旧版对话保留导入入口。

「发现」中的 **NSFW · 成人写真** 开关，会让新人物偏向成年写真创作者、性感穿搭博主的公开主页风格：暧昧签名、写真兴趣与粉丝互动，照片可采用泳装、内衣等性感穿搭的非露骨写真。关闭时为日常交友与生活照。切换后刷新生效，已有卡片、补画和人物扩写沿用发现时的模式。来信由按钮触发；图片失败可单独补画，付费图片沿用费用确认。

## 配音、绘图与助手

**正文配音**支持角色音色、逐句播放、「听取」和整篇朗读。可收藏生成的音频；开启语音缓存后，已有缓存用于重播。

**绘图**支持独立出图和正文配图，可管理角色外观、参考图、Vibe、画风与连接方案。ComfyUI 的工作流、模型、LoRA 和参数在「绘图」中管理，支持导入 API 格式 JSON 或酒馆工作流。生成结果受模型、参考资料与参数影响。

**助手「小此」**拥有独立会话，能讨论剧情、处理附件，也能按要求调用手机功能，例如录入商品、生成商品图、购买穿戴、管理角色、预设与备忘录。实际调用的操作和结果会显示在会话中。

相册、备忘录、音频收藏、音效，以及主题、壁纸、头像和挂件，可在手机内分别管理。背景音乐和音效需要自行添加音源。

### 可连接的服务

| 用途 | 支持的连接 |
| --- | --- |
| 文字 | 酒馆当前模型、独立 OpenAI 兼容接口、Google Vertex AI |
| 语音 | Fish Audio、MiniMax、ElevenLabs、小米 MiMo、火山引擎豆包语音、自定义语音接口 |
| 绘图 | NovelAI、GPT 生图、ComfyUI |

文字模型可在「引擎 → 文字模型」单独配置，正文仍使用酒馆自己的模型。Fish Audio 支持 API 密钥和「订阅积分（官方 MCP）」两种接入方式；TauriTavern 的账户连接与 MCP 设置见 [接入说明](Fish订阅积分接入.md)。

## 角色状态、异构终端与衣柜商城

### 角色状态与异构终端

「角色状态」集中显示主角和已记录角色的当前外貌、体型、下体外观与状态，以及四类衣物。字段可以分别编辑和锁定；剧情同步保留未提及内容与已锁定项。状态记录随当前聊天和楼层快照保存，回退时恢复对应进度。

「异构终端」提供附身、融合、寄生、丸吞、肉体改造和认知修改，管理当前形态、目标与身体来源。衣柜和角色状态共用相关记录；穿戴的身体、头部、音色及独立部位按实际生效来源判定。

规则、同步要求和设计工作台提示词可在「预设 → 异构」中编辑、开关或恢复默认。字段锁定约束会提供给剧情模型，实际描写仍取决于模型回复。

### 衣柜与购物商城

- **购买与穿戴**：商品先购买入柜，再选择穿戴目标；皮躯和肉躯支持多层穿戴，肉躯的前后延展可独立开关。
- **直接入柜**：自制、获赠或已获得装备可在衣柜登记，无需经过商城购买。
- **完整装备档案**：可编辑身体类型、外貌、结构覆盖、特殊能力与条件、永久绑定音色和商品图片。
- **手动或 AI 进货**：手动填写设定与售价即可上架，不调用设计模型；AI 进货可提供文字、参考图和指定身体类型，并使用当前启用的异构预设与比例尺。
- **同人商品**：进货或编辑皮躯／肉躯时勾选「同人」，角色／身体提示词会加入 `角色名 (cosplay)`，例如 `hatsune miku (cosplay)`。AI 进货可识别角色 Tag，手动录入需填写；该 Tag 不加入器官提示词。
- **提示词分离**：角色／身体与器官提示词分别保存，按实际生效部位用于绘图。商品图与当前形态图会过滤 `masterpiece`、`best quality` 等通用质量词。
- **删除单品**：衣柜与商城的商品卡均可点击「×」确认删除，包括初始商品。删除会同时移除商品与对应穿戴，不退款，重新载入不会补回。
- **批量管理**：支持无图 JSON 导入、导出。普通上新使用增量导入；图片在商城中另行上传或生成。

角色状态与穿戴进度跟随当前正文聊天；商城目录、衣柜库存和异构预设作为共享资料保留。开始新聊天会重新初始化剧情状态，保留的旧聊天可恢复原进度。

### 在 Codex 中批量进货

仓库附带 [revophone-mall-restock 技能](skills/revophone-mall-restock/SKILL.md)。将该目录安装到 Codex 的 `~/.codex/skills/` 后，可以这样使用：

```text
$revophone-mall-restock 制作 20 件奇幻旅行商品：8 件女性皮躯、4 件肉躯、8 件服饰，价格 200–2000，填写能力及限制，输出商城导入 JSON。
```

技能制作商品资料并校验分类、售价、槽位、编号与字段长度，导出 `revophone-mall-items` 格式的无图文件；也可读取导出的异构预设，沿用启用的比例尺。文件在「购物商城 → ＋ 进货上架 → 批量导入/导出」导入。普通追加商品不勾选覆盖替换；沿用稳定 ID 的增量重导可更新原商品，技能导出时省略购买状态，避免把已购商品改回未购买。

## 费用、保存与备份

RevoPhone 本身免费，联网功能使用你配置的服务及其额度：

- 文字回复、AI 设计和剧情同步等操作会调用文字模型；手动编辑状态或录入商品不调用设计模型。
- 播放、通话和语音提前生成等操作可能产生语音用量；已有缓存可直接重播，缓存清理后可能需要重新生成。
- 绘图费用取决于引擎、账户和参数。插件的 NovelAI 生图路径设有免费档守卫与付费确认，具体设置在「绘图」中查看。

资料默认保存在当前浏览器中。「设置 → 保存到酒馆」可将聊天、记忆、助手会话、朋友圈、备忘录和相册等支持的资料保存到自己的酒馆账户；密钥、语音缓存和收藏音频不随这项同步迁移。

普通 API 密钥在本地保存，Vertex 连接使用酒馆保存的凭据；请求内容会发送到所选服务或配置的中转地址。Fish OAuth 与 TT MCP 授权的保存位置及断开方式见 [接入说明](Fish订阅积分接入.md)。

「设置 → 备份到文件」可选择导出资料，默认不带密钥；若勾选密钥，需要设置密码加密。带密钥的加密备份需要 localhost 或 HTTPS 环境。换设备前请确认同步完成，或保存并妥善保管备份文件。

## 遇到问题

| 情况 | 先检查这里 |
| --- | --- |
| 正文没有声波 | 「设置 → 正文语音」是否开启，以及回复中的台词格式提示。 |
| 有字幕但没有声音 | 角色是否绑定音色，语音服务是否配置成功。 |
| 提示 401 或连接失败 | 「引擎」中的连接地址、密钥、模型与账户额度；重新粘贴密钥后保存。 |
| 正文没有自动出图 | 「设置 → 正文出图」、绘图引擎连接，以及「绘图 → 正文出图」的自动生成选项。 |
| 更新后仍是旧界面 | 刷新页面，或重新打开扩展／重启 TauriTavern。 |
| 不清楚问题出在哪里 | 打开「日志」查看对应请求，再到「设置 → 自检」导出报告。 |

提交 [Issue](https://github.com/RevolvinDoor/RevoPhone/issues) 时，请附插件版本、宿主与设备、复现步骤、错误提示或自检报告。分享前检查日志、截图和请求内容，移除密钥及不想公开的聊天资料。

更详细的配置、标签格式与联动说明见 [使用说明](使用说明.md)。

## 正文重写联动

可选安装 [Auto-Rewrite 原生 Swipe 适配版](https://github.com/RevolvinDoor/SillyTavern-Auto-Rewrite) 3.1.2 或更新版。自动重写时，手机自动联动等待最终保留稿并只计一次；失败／取消使用原稿。事后手动重写更新正文绑定数据，保留已发生的独立活动；切换原稿／重写稿同步角色状态和手机消息，已回复的手机对话保留。未安装、已禁用或没有重写时，RevoPhone 继续原有流程。详细边界见 [使用说明](使用说明.md)。
